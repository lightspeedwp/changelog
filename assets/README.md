# Assets

Design tokens, templates, and shared resources.

## Contents

- **Design Tokens** - Color schemes, typography, spacing
- **Templates** - Email templates, document templates
- **Icons** - Icon sets and SVG assets
- **Fonts** - Custom fonts for documentation

## Using Assets

Reference assets from documentation:
```markdown
See [design tokens](assets/) for color definitions
Use [templates](assets/templates/) for consistent formatting
```

## Standards

All assets should:
- Follow LightSpeed WP brand guidelines
- Include metadata and version info
- Have clear usage instructions
- Be tested for accessibility
